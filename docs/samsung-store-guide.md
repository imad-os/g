# Samsung TV store: submission guide and how to avoid rejection

This guide is compiled from Samsung's Seller Office launch checklist, development checklist, icon
guide and certification FAQ (sources at the end), plus the defects Speedy IPTV received. Each item
is mapped to what Arcade does.

## 1. Before you upload

| Requirement | Arcade |
|---|---|
| `config.xml` `<name>` is **identical** to the default-language title in Seller Office | `Arcade`. Enter exactly this, or change both. If "Arcade" is already taken in the store, pick a unique title (e.g. "Arcade Pocket Games") and update `<name>` |
| Tizen ID / package ID unique, never changes between versions; no special characters | replace `XXXXXXXXXX` in `config.xml` with the ID from Seller Office |
| Version `[0-255].[0-255].[0-65535]`, higher on every upload | `1.0.0`. Bump for every `.wgt` |
| Screen size declared in a `<feature>` | `http://tizen.org/feature/screen.size.all` |
| Only the privileges you use; no partner or unavailable privileges (`keymanager`, `systemmanager`, `websetting`) | `internet`, `tv.inputdevice`, `network.public` (network popup) |
| Signed with a **Samsung** certificate; updates signed with the **same author certificate** | keep the `.p12` and its password safe. Losing it means you can never update the app |
| App icon in the package: 512×423 PNG, < 300 KB | `icon.png` (24-bit, 22 KB), `<icon src="icon.png" width="512" height="423"/>` |

## 2. Seller Office assets (generated by `tools/make-store-assets.mjs`)

| Asset | Spec | File |
|---|---|---|
| Icon 512×423 | 24-bit PNG, < 300 KB | `icon.png` |
| Logo 1920×1080 | 32-bit PNG **with transparency**, < 300 KB, inside the centre safe area (a 1:1 crop is made from it) | `store/logo_1920x1080.png` |
| Background 1920×1080 | 24-bit PNG or JPG, < 300 KB | `store/background_1920x1080.jpg` |
| 4 screenshots | 1920×1080 JPG, < 500 KB each | `store/screenshot_1..4.jpg` |
| Title + description in **every language the app supports** | EN, FR, ES, AR: use the game descriptions in `games/*/game-manifest.json` |
| Privacy policy URL | `https://imad-os.github.io/g/privacy.html` (after GitHub Pages is on) |
| Contact e-mail, age rating questionnaire | age rating: cartoon platform action, no blood, no online interaction → lowest rating |
| **App UI Description** file | must use **Samsung's template** without changing its structure. Content to paste is in section 5 |

You cannot change the title, category, icons or countries while the app is in certification.
Upload them right the first time.

## 3. Why testers reject TV apps, and Arcade's status

| Typical defect | Status in Arcade |
|---|---|
| Crash, freeze or black screen (also with no network / slow network / server down) | bundled copy runs offline. Automated tests cover offline, broken hosted build and blacklisting |
| Launch longer than **10 s** (5 s ideal) | splash at once. The menu appears in about 0.2 s offline, or at most 2.5 s waiting for the hosted manifest |
| **No popup when the network is disconnected** (Speedy was rejected for this) | `#netpop` alert on disconnect and on reconnect, in menus and in games (tested) |
| Back/Return key does nothing, or exits without confirmation | Back: game → pause menu → quit to menu; main menu → exit confirmation (tested). One handler, no double back |
| Multitasking: app not paused or audio still playing after Home, or state lost | `visibilitychange` → pause menu + `AudioContext.suspend()`. Stays paused on return |
| Voice Guide reads nothing or garbage | real DOM focus, labels on every item in all 4 languages, live region for status, decorative images hidden |
| UI cut off or misaligned on some model years | layout at 1920×1080, scaled to fit; plain CSS for Chromium 56+ |
| Default language not English in the US | follows the TV language, falls back to English |
| Language change not applied everywhere (Speedy defect) | every string goes through `I18n` and is re-applied on change. Games pick up the language on launch |
| OK key activates twice | keydown `preventDefault`. Tested: one activation per press |
| Screensaver during play (gamepad users never touch the remote) | screensaver off while a game runs, back on when paused or in the menu (`webapis.appcommon`) |
| Uninstall must delete all app data | everything on the TV is in the app's own `localStorage`, removed with the app. The optional cloud backup (Firestore `tvs/<id>`) stays online so a reinstall can restore it; people can delete it in Settings > Privacy & security. Mention the backup and the world records (player name + score) in the privacy policy you give Seller Office. |
| IP / copyright (names, characters, look-alike designs) | all art, music and names are original. Block Drop uses its own well size (12×18) and colours. Tile Merge has its own palette. No "Mario/Tetris" wording anywhere in the package |
| Missing test info | no login, no purchases, no region lock. Say so in the App UI Description |
| Content not reachable by testers (geo/IP block, test server) | none. The hosted copy is public on GitHub Pages |
| Features that change after certification | hosted updates are limited to fixes and content (see README). **Do not** use them to add new behaviour that Samsung has not tested |

## 4. Before every submission

1. `npm test`: all checks must pass.
2. Install the signed `.wgt` on the **oldest** and the **newest** TV you target. Do the
   walk-through in `docs/certification.md`: Back everywhere, Home and return, network cable
   unplugged at launch and during play, Voice Guide on, every language, gamepad plugged and
   unplugged.
3. Check that the version is higher than the last upload, `<name>` = Seller Office title, and the
   same author certificate is used.
4. If you changed `config.xml`, `index.html` or the loader since the last release: bump `SHELL`
   and `shell` (README → Online updates).
5. Fill the App UI Description (section 5) and attach it.

## 5. App UI Description: content for Samsung's template

**Overview:** Arcade is a launcher with six original offline games: Super Jumper (platformer,
1–2 players), Block Drop, Sky Hopper, Neon Snake, Brick Breaker and Tile Merge. There are no
accounts, login, purchases, ads, video or region restrictions. Top-10 score tables and progress
are stored locally. At start the app checks `https://imad-os.github.io/g/` for content updates and
works fully without a network.

**Main screens:**
1. **Main menu:** grid of 6 game tiles, plus *Top scores* and *Settings* buttons at the top right.
2. **Top scores:** 6 columns, one top-10 table per game.
3. **Settings:** language (EN/FR/ES/AR), music volume, effects volume, graphics quality, controller
   help, reset progress, privacy policy, about (version/build).
4. **Game screen:** each game runs full screen. The pause menu has Resume, game options and Quit to
   menu.
5. **Super Jumper world map:** 3 worlds × 5 stages.

**Remote keys:**
- Arrows: move/navigate.
- OK: jump/confirm. Hold OK to jump higher.
- Return: pause in a game, back in menus, exit confirmation on the main menu.
- Play/Pause: pause.
- Red: run on/off in Super Jumper.
- Channel Up / Down: scroll a page (browser), previous / next month (calendar).
- Guide: Start menu on the desktop; in the browser, the toolbar on top (and back to the page); pause menu in a game.
- In Super Jumper, Up fires (when the hero has the fire power-up).

**Gamepad (optional):** D-pad/stick to move, A jump, B/X run or fire, Start/Select pause, LB/RB scroll a page, Guide/Home as the Guide key.

**Keyboard and mouse (optional):** arrows, Enter, Esc; Tab / Shift+Tab move between buttons; PageUp / PageDown scroll; F6 or the Windows key = Guide; mouse click, hover and wheel work everywhere. Settings > Devices lists what is connected and tests the controller buttons.

**Test scenarios:**
1. Launch → main menu (focus on the first tile) → OK → game loads with a progress bar → OK to start.
2. In a game press Return → pause menu → *Quit to menu* → focus returns to the same tile.
3. Main menu → Return → *Exit Arcade?* → Yes closes the app; No or Return stays.
4. Super Jumper → OK on stage 1-1 → play. Return → pause menu shows *Two players*. Choose it and
   press OK/A on a second controller (gamepad, or the remote if player 1 uses a gamepad) to add
   player 2.
5. End a game with a high score → the record is saved automatically for the active profile →
   main menu → *Top scores* shows it.
6. Unplug the network cable in any screen → popup "No network connection…". The games keep
   working. Reconnect → "Network connected".
7. Settings → Language → Left/Right changes the UI language immediately.

**Test account:** not needed (no login).
